# 配布候補の確認と引き渡し

**受け取るもの**　対象 OS、ビルド入口、固定した依存版、必須素材一覧、対応する既存セーブと入力装置。

**進め方**　ホストのプロフィールと catalog を照合する。クリーン環境で必要なライブラリ、フォント、音声、シェーダー、素材の権利・同梱条件を一覧化する。起動→最初のプレイ→保存→再読込の経路、前版からの更新、障害時の復旧を分ける。配布先・公開操作は依頼で指定された範囲に従う。

**引き渡すものと完了条件**　ビルド ID、対応環境、配布物、既知の制約、復旧手順、確認した経路。ローカルで起動した結果と、対象端末でプレイできた結果を個別に記録する。
