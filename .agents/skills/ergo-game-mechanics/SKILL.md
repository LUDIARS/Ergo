# 操作とゲームルールの実装

**受け取るもの**　ゲームループ仕様、操作割当、シミュレーションの更新単位、タイトルの状態所有者。

**進め方**　Ergo の `module_list.yaml` で input・actor・cast・world_time など利用可能な部分を確認する。入力イベント、ルール判定、演出要求を分離し、二重入力・ポーズ中・失敗後の再開始を通る具体例を作る。たとえば衝撃波の当たり判定とエフェクトの寿命は別々に扱う。

**引き渡すものと完了条件**　通常入力と境界入力それぞれの期待状態、変更先、ゲーム側の実装差分。見た目の変化だけでダメージ成立を判定しない。
