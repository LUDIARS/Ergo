# 難度と操作感の調整

## 初期セットアップ

ゲームの bind 宣言からアプリ名、公開名、型、範囲、読み取り専用属性を拾う。ホストの Studio プロフィールに `tuningTemplates` を組み立てる。既存グループは保持し、一緒に比較する値を一つのグループにまとめる。各グループには `title` と順番付きの `fields` を置く。各部品の `name` はゲームが公開する完全名を使う。

```json
{"tuningTemplates":{"amicii-server":[{"title":"バランス保存","fields":[{"name":"balance.saved","widget":"display"}]}]}}
```

範囲付きの数値は `slider`、直接入力する数値は `number`、真偽値は `toggle`、観測値は `display` を使う。値と単位、上下限はゲームが所有する。テンプレートの適用後、Studio の「調整値」で対象アプリを選び、未接続の項目と意図した部品を確認する。

**受け取るもの**　違和感のある場面、現行値・単位・有効範囲、ゲームが実際に読む値、比較用のプレイ条件。

**進め方**　`tools/studio/plugins/tuning/tuning_store.cpp` とホストの tuning プロフィールを確認し、基準版を特定する。仮説一つに対して変える値を絞る。例として敵 HP の調整では命中率・撃破時間・受けたダメージを記録し、単にプレイ時間が短くなったことと区別する。

**引き渡すものと完了条件**　旧値・候補値・単位・観測指標・戻し先。ライブ値だけを変更した場合は、再起動後に読むデータへ保存したかを別に記す。
