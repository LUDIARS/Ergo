# 難度と操作感の調整

**受け取るもの**　違和感のある場面、現行値・単位・有効範囲、ゲームが実際に読む値、比較用のプレイ条件。

**進め方**　`tools/studio/plugins/tuning/tuning_store.cpp` とホストの tuning プロフィールを確認し、基準版を特定する。仮説一つに対して変える値を絞る。例として敵 HP の調整では命中率・撃破時間・受けたダメージを記録し、単にプレイ時間が短くなったことと区別する。

**引き渡すものと完了条件**　旧値・候補値・単位・観測指標・戻し先。ライブ値だけを変更した場合は、再起動後に読むデータへ保存したかを別に記す。
