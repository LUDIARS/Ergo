# 操作に応じた映像・音・UI の制作

**受け取るもの**　イベント名、気付かせたい対象、カメラ距離、素材の出所と利用条件、描画・音声の予算。

**進め方**　行動前・成立時・終了時ごとに視覚と音の役割を決める。共通部品は `module_list.yaml`、制作ツールは `tools/studio/builtin_plugins.cpp` で確認する。`examples/lesson_action_feel/core/presentation.cpp` の命中時の表示を例に、タイトル側でイベントと演出を対応付け、素材を使う場合は参照する素材 ID も記録する。色だけに依存する状態には形やタイミングを添える。

**引き渡すものと完了条件**　素材仕様または素材差分、イベント対応表、音量・表示時間・同時発生上限、プレビュー条件。多重発生と消滅時にも操作対象を見失わないか観察できる。
