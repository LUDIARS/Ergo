# 再現できる試遊と観測

**受け取るもの**　対象ビルド、目標、操作表、開始状態、観測できるログ・画面・フレーム指標。

**進め方**　手動なら操作手順と期待結果を書き、AI 試遊なら対象タイトルの試遊ルールを実際の入力割当・終了条件と照合する。比較時はビルド、初期状態、入力列を記録し、乱数を使う場合はシードも固定する。成功・失敗・再試行を分け、画面・入力・ゲーム状態を同じ時刻に対応付ける。対象端末でフレーム時間を測り、組み込み済みなら `ergo_perf` のフレーム統計と `ergo_profile` のトレースを使う。

**引き渡すものと完了条件**　再現可能な試遊票、観測事実、改善仮説、次に比較する版。実行許可や実機がなければ試遊票までを成果とし、対象端末での結果を未確認と記す。
