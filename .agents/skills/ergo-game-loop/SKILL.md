# 遊びの核とゲームループの設計

**受け取るもの**　遊ぶ人、核となる操作、想定する一回のプレイ時間、対象ゲームの既存仕様。

**進め方**　一場面を選び、入力→状態変化→画面・音の応答→次の選択を記述する。開始、成功、失敗、やり直しを定める。たとえば拍に合わせて転がすゲームなら、拍の判定窓と時刻の基準をタイトル側の実装で確認し、入力と判定結果をそれぞれの時刻とともに残す。

**引き渡すものと完了条件**　一枚のプレイ仕様と、実装すべきタイトル側の状態遷移、担当モジュール、観察例。初見の人が一周分の操作をたどり、成功・失敗の違いを説明できる。
