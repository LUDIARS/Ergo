# ステージとシーンの制作

**受け取るもの**　レベルの狙い、スポーンとゴール、タイトルのスキーマと既存ステージ一件。

**進め方**　対象タイトルの編集スキーマ、既存ステージ、実行時の読み込み処理を照合する。安定 ID、単位、座標系、参照先、到達可能性を確認し、入口→習得→応用の経路を作る。ルック調整には Ergo の `src/scene/scene_patch.cpp` を参照する。ゲーム進行データの形式はタイトルに従う。

**引き渡すものと完了条件**　ステージ差分、変更した ID、期待する経路と失敗時の復帰地点。保存後に同じ場所・同じ対象として再読込できることを受入条件とする。
