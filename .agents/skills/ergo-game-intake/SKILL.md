# プロジェクトの受け入れ

**受け取るもの**　ゲームのリポジトリと対象プラットフォーム。既存の Studio プロフィール、ビルド入口、ゲームが読むデータの場所。

**進め方**　`src/studio/project/project_style.cpp` で様式の判定根拠を調べ、プロフィールの `style` が指定されていれば優先する。`tools/studio/plugins/common/workspace_profiles.cpp` を参照し、プロフィールの `root` を基準に `assets` の素材パスと `tuning` の保存先を照合する。`play` のビルド・起動設定と入力割当は対象ゲームで定義されている実際の設定と照合する。

**引き渡すものと完了条件**　対象、存在する入口、不足、所有リポ、次に必要な人間判断の一覧。初回起動できなくても原因を「プロフィール欠落」「実行先未定」「未確認」に分けられる。
